# 何为悠然
悠然是由腐竹 QinguMoe 开设的，一个从 2021 年开到现在的 Minecraft Java 1.12.2 模组公益服。

- **悠然坚持存档永不重置。**我们服务器没有周目、赛季，不会重置存档。当前存档从 2021 年开服已经一直用到今天。虽然从 2024 年开始，服务器关了近两年，但 2026 年重开时仍是原来的存档。
- **悠然认为世界应当是活的。**我们服务器的世界自己会变化，而非在自然状态下一成不变。例如，SCP 收容失效时会跑出来，有人在城区撞见过不知从哪来的恐龙，也有人不小心放出了会传染的霉菌，差点引起疫情。你可能会碰上别人以前留下的痕迹，也可能为以后的人埋下谜团。
- **悠然设计的是有机联系的玩法。**我们服务器不靠不停加新模组、新奖励来丰富内容，而是尽量把已有的模组接在一起。一样东西不光在这里有用，在另一个模组里也可能有用。有些联系容易找到，有些联系则藏得深，但无论如何，只要发现便并不难理解。找不到新的联系？翻翻手册、看看地图，问问老玩家，甚至自己做点实验，或许有新的发现（？
